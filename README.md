## Purpose of the repository :
The purpose of this repository is to perform and demonstrate basic Git and GitHub operations such as creating a repository, adding files, staging files, committing changes, pushing changes to GitHub, and cloning a repository


## Objectives of the Practical :
1.  To understand the basic concepts of Git and GitHub.
2.  To create and manage a Git repository.
3.  To learn how to track, stage, commit, push, and clone files.
4.  To understand how to work with GitHub repositories.
5.  To practice using basic Git commands.

## Git Commands Learned :
1. `git init` – Initialize a Git repository.
2. `git status` – Check the current status.
3. `git add` – Add files to the staging area.
4. `git commit` – Save changes to the repository.
5. `git log` – Display commit history.
6. `git remote` – Connect the local repository to GitHub.
7. `git push` – Upload changes to GitHub.
8. `git clone` – Clone a GitHub repository.
9. `git diff` – Display changes made to files.
