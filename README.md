## Purpose of the repository :
The purpose of this repository is to perform and demonstrate basic Git and GitHub operations such as creating a repository, adding files, staging files, committing changes, pushing changes to GitHub, and cloning a repository

## Git Commands Learned

1. `git --version` - Check Git installation
2. `git config --global user.name "Name"` - Set username
3. `git config --global user.email "email"` - Set email
4. `git init` - Create a new Git repository
5. `git status` - Check repository status
6. `git add .` - Stage all changed files
7. `git commit -m "message"` - Save staged changes
8. `git log` - View commit history
9. `git branch` - List branches
10. `git switch branch-name` - Switch branch
11. `git remote -v` - View remote repositories
12. `git push origin main` - Upload commits to GitHub
13. `git pull` - Download and merge latest changes
14. `git clone repository_url` - Copy a remote repository
15. `git diff` - See unstaged changes
